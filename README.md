# Adult Income Analysis

## Overview
This project explores the Adult Income dataset to analyze demographic and employment-related factors associated with income levels. The main objective is to understand patterns in the data and investigate which features may be related to earning more than $50,000 per year.

## Dataset
The Adult Income dataset contains demographic and socioeconomic information, including features such as:

- Age
- Workclass
- Fnlwgt
- Education
- Education num
- Marital status
- Occupation
- Relationship
- Race
- Sex
- Capital gain
- Capital loss
- Hours per week
- Native country
- Income

## Tools and Libraries
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
